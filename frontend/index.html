Le projet EiffelPulse

Plateforme construite dans le cadre d'une candidature en alternance Concepteur / Développeur Full-Stack et IA à la Société d'Exploitation de la Tour Eiffel.

Architecture

Backend
Python 3.12 · Flask 3 · SQLAlchemy · Flask-CORS
IA / ML
scikit-learn (TF-IDF, LogReg, GradientBoosting) · script DistilBERT LoRA (PyTorch + HuggingFace)
Data
Pandas · NumPy · 5 000 avis multilingues · 13 035 points horaires
Frontend
Tailwind CSS · Alpine.js · Chart.js · responsive design
Scraping
Selenium 4 · BeautifulSoup · mode dégradé
Qualité
pytest · Playwright (e2e screenshots)
